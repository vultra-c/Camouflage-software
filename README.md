# LED 时钟 · 伪装轻应用（小米手环 9 Pro）

一个面向 **小米手环 9 Pro（336×480，Vela 系统）** 的伪装轻应用。

打开后，整块屏幕就是一块**普通的老式黑底红色 LED 电子表**：
纯黑背景、红色发光 7 段码数码管数字、实时刷新到 **秒**，
除了这块"表"没有任何其他功能、菜单或提示——查手环时一眼看上去就是一块 LED 电子表。

## 唯一的退出方式

- **右滑 / 返回键：无效。** `onBackPress` 始终返回 `true`，页面永远不会退出。
- **唯一退出方式：6 秒内连续点击屏幕（时间数字）10 次**，应用静默退出（`app.terminate()`）。
- 点击计数 6 秒无操作自动清零，不会误触发。
- 除此之外没有任何手势、按键、组合键可以退出。

## 项目结构

```
├── package.json          # 构建脚本（aiot-toolkit 官方工具链）
└── src/
    ├── manifest.json     # designWidth=336，适配手环 9 Pro；仅声明 system.app
    ├── app.ux            # 应用入口
    ├── common/icon.png   # 应用图标（7 段码风格）
    └── clock/
        ├── index.ux      # LED 表盘页：时钟 + 秒级刷新 + 拦截右滑 + 连点 10 次退出
        └── digit.ux      # 7 段码数字子组件
```

## 显示内容

- 第一行：`月-日` + `星期`（如 `09-25 THU`）
- 第二行：`时:分:秒`（24 小时制，**每秒实时刷新**，冒号光点随秒闪烁）
- 第三行：`24H` 标记

全部以红色发光 7 段码（数码管）风格呈现在纯黑背景上，与真实黑底红字 LED 电子表一致。

## 构建

```bash
npm install
npm run build     # 生成 dist/xxx.rpk
```

> 也可使用 AIoT IDE 打开本项目，点击 Package 构建并配合模拟器调试（设备选择 xiaomi_band_pro）。

## 安装到手环

生成的 `.rpk` 推荐通过 [AstroBox](https://www.bandbbs.cn/) 推送到手环安装运行（米坛社区 BandBBS 有详细教程）。

## 设计初衷

供在校住校的学生在查手环时"蒙混过关"：
打开即是一块再普通不过的黑底红字 LED 电子表，没有应用名、没有多余 UI，
右滑退不出，只有自己知道"连点 10 下"才能退出。

## 预构建安装包

`release/` 目录内含打好的 rpk，可直接下载安装：

- `com.bandbbs.lcdclock.release.1.0.0.rpk` —— 正式版，日常使用装这个
- `com.bandbbs.lcdclock.debug.1.0.0.rpk` —— 调试版，连电脑看日志用
